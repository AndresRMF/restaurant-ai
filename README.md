# Restaurant AI

This is a personal project for experimenting with AI in a restaurant context.  

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/AndresRMF/restaurant-ai.git
cd restaurant-ai
```
### 2. Create and activate a virtual environment (optional but recommended)
```bash
python -m venv venv
source venv/bin/activate   # On Linux/Mac
venv\Scripts\activate      # On Windows
```

### 3. Add your OpenAI API key:
```bash
OPENAI_API_KEY=your_api_key_here
```

### 4. Run the backend:
```bash
python -m uvicorn main:app --reload
```

### 5. Open the index.html with the live server!
